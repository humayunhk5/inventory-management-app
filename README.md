# BizStock Inventory SaaS

BizStock is a professional inventory management application designed for small businesses, restaurants, retail shops, warehouses, and multi-location stores.

## Features

- Dashboard overview
- Product and stock management
- Sales tracking
- Purchase tracking
- Customer and supplier records
- Reporting and charts
- Subscription pricing plans
- Simple, clean UI suitable for business use
- Local browser storage for quick demo use

## Tech Stack

- Next.js
- React
- CSS Modules / custom CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000

## Production Notes

This is a working MVP starter for a SaaS inventory app. You can extend it with:

- PostgreSQL database
- Stripe billing
- User authentication
- Multi-tenant business accounts
- CSV / PDF export
- Barcode scanning
- Print invoices / receipts

## Business Use

This app is built to support subscription-based SaaS selling for businesses such as:

- Retail shops
- Restaurants
- Grocery stores
- Warehouses
- Wholesale suppliers
